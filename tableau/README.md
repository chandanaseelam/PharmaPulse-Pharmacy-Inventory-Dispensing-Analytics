# Tableau Public — PharmaPulse Sales & Dispensing Analytics

## Project Overview

As part of my PharmaPulse Pharmacy Analytics project, I developed three Tableau dashboards to analyze pharmacy sales, dispensing activity, and business performance.

The goal of this project was to transform pharmacy transaction data into meaningful visualizations that help track revenue trends, understand medicine demand, and compare performance across stores and product categories.

The dashboards are built using Tableau Public and a synthetic pharmacy dataset.

## Live Tableau Dashboard

**[View Interactive Tableau Dashboards](https://public.tableau.com/app/profile/chandana.seelam/viz/PharmaPulse-PharmacySalesDispensingAnalytics/03StoreandCategoryInsights)**

## Dashboards

### 1. Executive Sales Overview

This dashboard provides an overview of pharmacy sales performance, including total revenue, gross profit, units dispensed, and transaction volume.

It also displays monthly revenue and profit trends to help understand how business performance changes over time.

![Executive Sales Overview](screenshots/01%20_%20Executive%20Sales%20Overview.png)

### 2. Dispensing and Demand

This dashboard focuses on dispensing activity, transaction volume, and monthly demand patterns.

It helps explore how dispensing activity changes over time and provides a clearer understanding of overall pharmacy demand.

![Dispensing and Demand](screenshots/02%20_%20Dispensing%20and%20Demand.png)

### 3. Store and Category Insights

This dashboard compares pharmacy sales across stores and medicine categories.

It helps identify differences in revenue contribution, gross profit, and product-category performance.

![Store and Category Insights](screenshots/03%20_%20Store%20and%20Category%20Insights.png)

## Tools and Technologies

- **Tableau Public:** Interactive dashboard development and publishing
- **CSV:** Structured pharmacy transaction data
- **Tableau Hyper Extract:** Packaged data source
- **Calculated Fields and Aggregations:** Revenue, profit, dispensing, and transaction metrics

## Project Scope

The current Tableau workbook focuses on sales and dispensing analytics.

Inventory monitoring, stockout analysis, and supplier performance are covered separately in the project's Python and Plotly dashboards.

Future Tableau enhancements may include inventory availability, replenishment alerts, and supplier delivery performance.

## What I Learned

Through this project, I gained practical experience in:

- Connecting and exploring structured datasets in Tableau
- Creating KPI-based business dashboards
- Visualizing revenue and dispensing trends
- Comparing store and product-category performance
- Organizing multiple dashboards within a Tableau workbook
- Publishing dashboards through Tableau Public

## Dataset Information

All data used in this project is synthetic and created for educational and portfolio development purposes. The financial and operational metrics represent simulated pharmacy activity rather than actual business performance.
