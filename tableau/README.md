# Tableau Public — PharmaPulse Sales and Dispensing

## Open the working workbook

- [Download the packaged workbook](PharmaPulse_Sales_Tableau_Window_Fixed_v2.twbx)
- [View the published Tableau visualization](https://public.tableau.com/app/profile/chandana.seelam/viz/PharmaPulse-PharmacySalesDispensingAnalytics/03StoreandCategoryInsights)

This `.twbx` is the corrected **v2** file the project author opened successfully in Tableau Public Desktop and subsequently published. It contains the packaged sales data extract. Do not use the older experimental starter files, which failed to load.

## Three existing Tableau dashboards

1. Executive Sales Overview — revenue, profit, dispensed units, transactions, and monthly trends.
2. Dispensing and Demand — sales/dispensing volume and time trends.
3. Store and Category Insights — category and store comparisons.

**Scope note:** Tableau currently covers **sales and dispensing only**. The inventory and supplier dashboards are part of the separate Plotly HTML site. `Tableau_Calculated_Fields.md` and `Tableau_Dashboard_Build_Guide.md` are optional plans for extending Tableau to those areas; they do **not** claim those views have been completed in the current workbook.

## Data

The `.twbx` contains the embedded Tableau `.hyper` extract. `data/tableau_transactions.csv`, `data/tableau_fact_tableau.csv`, and related datasets in the repository can support future extensions, but the existing workbook is based on a sales data source.

**Data is completely synthetic and for learning purposes.**
